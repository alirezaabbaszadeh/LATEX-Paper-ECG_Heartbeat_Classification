The raw ECG recordings analysed in this work originate from the MIT-BIH Arrhythmia Database on PhysioNet (DOI: \url{https://doi.org/10.13026/C2F59R}) and are distributed under the Open Data Commons Attribution License v1.0. All preprocessing scripts (\texttt{preprocess\_data.py}, \texttt{create\_batched\_tfrecords.py}) and model training/evaluation code required to regenerate intermediate features, beat annotations, and folds are included in the project repository (\url{https://github.com/alirezaabbaszadeh/LATEX-Paper-ECG\_Heartbeat\_Classification}). The submission references repository snapshot \texttt{b0500a4} and bundles the derived TFRecords, cross-validation splits, experiment logs, figure source files, and trained checkpoints for every run discussed in the manuscript under \texttt{Research\_Runs/}, enabling full reproduction without external archives or credentials.
