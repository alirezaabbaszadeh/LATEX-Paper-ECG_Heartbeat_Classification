\subsection*{Data Availability}
This study uses the MIT-BIH Arrhythmia Database available from PhysioNet (\url{https://physionet.org/content/mitdb/1.0.0/}), distributed under the Open Data Commons Attribution License v1.0; the corresponding license text is provided on the PhysioNet project page. All preprocessing scripts (\texttt{preprocess\_data.py}, \texttt{create\_batched\_tfrecords.py}), training and evaluation code, and generated artifacts (TFRecords, fold splits, logs, and trained checkpoints) are provided in a public GitHub repository. Code and experiment artifacts are available at \url{https://github.com/alirezaabbaszadeh/ECG_Heartbeat_Classification}. The repository also contains the exact configuration files and saved outputs for the runs referenced in this manuscript, enabling full reproduction of the reported metrics and figures.

\subsection*{Ethics}
Ethics approval and informed consent were not required because this study used the publicly available, fully de-identified MIT-BIH Arrhythmia Database. No new human or animal data were collected.
