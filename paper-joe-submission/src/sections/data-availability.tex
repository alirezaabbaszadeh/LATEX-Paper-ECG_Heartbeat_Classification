The MIT--BIH Arrhythmia Database is openly available from PhysioNet at \url{https://physionet.org/content/mitdb/1.0.0/}. Source code, experiment configurations, trained models, and the prediction arrays used for the analyses are available in the public ECG Heartbeat Classification repository at \url{https://github.com/alirezaabbaszadeh/ECG_Heartbeat_Classification}. The exact reproducibility snapshot used for the reported results is preserved in the immutable software release at \url{https://github.com/alirezaabbaszadeh/ECG_Heartbeat_Classification/releases/tag/v1.0-joe-submission}.
